## 🛠 Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (or React/Vue if applicable)
- **Styling**: Tailwind CSS
- **Storage**: Browser LocalStorage + IndexedDB
- **Deployment**: Static hosting (Vercel / Netlify / Cloudflare)

## 📖 How to Use

1. Go to [notepad.is](https://notepad.is)
2. Start typing immediately
3. Your content auto-saves
4. Click **Share** to generate a shareable link
5. Access from any device using the same link or revisit the site

### Keyboard Shortcuts
- `Ctrl/Cmd + S` — Manual save
- `Ctrl/Cmd + Shift + K` — Toggle Dark Mode
- `Ctrl/Cmd + Enter` — Quick actions (customizable)
